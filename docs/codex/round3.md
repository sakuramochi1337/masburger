# Round 3（Claude → Codex）：D2 片付けのルール案

前回までの改修（P2P・段ボール配送）は入った。次は D2 片付け。短く反対意見をください（最大5点）。

## 現状
- イートインはハードだけ（席までトレーで運ぶ）。食べ終わるとトレーは勝手に消える。イージー/ノーマルは客が受け渡し口で受け取って帰るだけ。
- 置き物（freeItems）は全員に同期され、拾う・置く・ゴミ箱は既存の仕組みで動く。

## 案
1. **汚れの発生源**
   - 食べ終わったトレー：イートインの客が帰ると、席に「食べ終わったトレー」が残る。そのテーブルは片付けるまで次のイートイン客に使われない（ハードではテイクアウト扱いになり紙袋の手間が増える）。
   - ゴミ：帰る客の約15%が客席の床に包み紙やカップを落とす。
   - ノーマル/イージーにも「店内で食べる客」を追加：受け渡し口で受け取った客の約30%が、きれいな空席があればトレーを持って自分で席に座り、10秒食べて帰る（スタッフが席まで運ぶ手間はない）。→ どの難易度でも片付けの仕事が出る。
2. **片付け方**：トレーは E で持ってゴミ箱へ。床のゴミは E で拾い、続けて拾うと手に5個まで重なる。ゴミ箱は厨房の奥に加えて、客席の入口脇にも1つ置く。
3. **汚れの点数**：トレー2点、ゴミ1点。0〜1 ピカピカ / 2〜4 ふつう / 5〜8 汚れ気味 / 9〜 汚い。HUD に常時表示。
4. **効果**（初見の人が少し放置しても即死しない強さにしたい）
   - 汚れ気味：新しい客の我慢 0.9倍、チップ 0.6倍、完璧に出しても★4「料理は良いけど店が汚れていた」（評判の上がりが小さい）
   - 汚い：我慢 0.8倍、チップ 0.3倍、完璧でも評判が少し下がる。来店客の30%が入口で引き返す
   - 閉店時に残った汚れ1点につき清掃代 ¥80（日報に表示）
5. **設備投資「トレー返却口」¥2000**：イートイン客の半分が自分でトレーを返却口に返して帰る。
